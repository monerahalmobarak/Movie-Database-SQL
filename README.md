# Movie Database SQL
As part of the Database Fundamentals course, we Designed a database for VOX Cinemas,
including creating an ERD and relational schema, writing DDL commands and inserting 
statements and running queries. Demonstrates knowledge of database fundamentals.

A comprehensive SQL-based solution to manage a movie database efficiently. This repository includes SQL scripts to create, populate, and manage a database designed to store information about movies, directors, actors, and related entities.

## Features

- **Database Schema:** Predefined schema for movies, directors, actors, genres, and more.
- **Data Population:** Scripts to populate the database with sample data.
- **Query Examples:** Optimized SQL queries for common use cases, such as searching movies by genre, fetching director details, or listing top-rated movies.
- **Performance Optimization:** Indexing and normalization techniques applied to ensure high performance.
